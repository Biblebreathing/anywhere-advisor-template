## Colors
| Role | Hex | Use |
|---|---|---|
| Primary | `#4B4C4D` | Charcoal from the logo: headers, key shapes |
| Primary-strong | `#4B4C4D` | Buttons and links (8.6:1 with white text) |
| Primary-tint | `#EDEDED` | Light section backgrounds, cards |
| Accent | `#C8963E` | Logo gold: highlights, underlines, icons, one key word in a headline. **Not** for long text or button text. |
| Ink | `#212122` | Headlines; dark sections |
| Body text | `#444546` | Paragraph text |
| Surface | `#F9F9F9` | Page background |

Contrast: all checks pass ✅ (body 9.1:1, headlines 15.3:1, buttons 8.6:1, gold on dark 6.0:1).

## Fonts (Google Fonts, free for web and print)
- **Headlines:** Playfair Display (the classic serif echoes the logo's serif wordmark)
- **Body:** Source Sans 3
- **Book interior:** body at 11–12pt, or a classic book serif. The final pick is in Stage 11.
