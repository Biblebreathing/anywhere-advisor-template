# Stage 11 — KDP Publishing

**Status:** ⏳ Not built yet

**Purpose:** Format the book for Amazon KDP paperback and Kindle, build the cover, and prepare the listing.

**Inputs:** Final edited manuscript

**Planned outputs:** print-ready interior PDF, cover PDF (with spine), EPUB, listing copy (title, subtitle, description, 7 keywords, categories)

**Working reference — confirm against current KDP Help before each print run:**
- Common trim: 6" × 9". Bleed (if images run to the edge): 0.125".
- Minimum inside (gutter) margin grows with page count: 0.375" (24–150 pp), 0.5" (151–300), 0.625" (301–500), 0.75" (501–700), 0.875" (701–828). Outside margins: 0.25" minimum, 0.375" with bleed.
- Spine width ≈ page count × 0.002252" (white paper) or × 0.0025" (cream).
- QR codes: print at 0.8" minimum, high contrast, and point to redirect links you control, so destinations can change without reprinting.
